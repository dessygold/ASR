Sonabot had this to say on the matter:
Sonatype Lifecycle (IQ Server) and Nexus Repository handle Prometheus integration differently:
Nexus Repository has a native Prometheus endpoint that directly exports metrics in Prometheus format:
/service/rest/metrics/prometheus (v3.81.0+)
/service/metrics/prometheus (v3.19.0–3.80.0)
Prometheus docs
Metrics REST API
Sonatype Lifecycle (IQ Server) does not have a native Prometheus endpoint. Its metrics API returns data in JSON format only:
http://localhost:8071/metrics?pretty=true
The documentation explicitly notes that while Prometheus cannot natively consume this JSON output, integration is possible through the use of exporters (for example, json_exporter) that transform the JSON output into a Prometheus-compatible format.
Operational Menu
In summary: Nexus Repository supports Prometheus natively, while Lifecycle requires an intermediate exporter (like json_exporter) to bridge the JSON metrics output into a Prometheus-compatible format.
